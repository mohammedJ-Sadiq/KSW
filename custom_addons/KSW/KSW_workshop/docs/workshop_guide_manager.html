Workshop Manager — Receive, Execute and Close a Request
لمدير الورشة والفني  ·  For the Manager & Technician
دورة الطلب أربع خطوات: تستلم الطلب، تبدأ العمل أو ترفضه، تُدخل تقرير الإصلاح، ثم تُنهي الطلب. أسماء الحقول والأزرار مكتوبة هنا بالإنجليزية كما تظهر على الشاشة.
Four steps: receive, start or reject, fill the repair report, close. Field and button names are shown in English exactly as they appear on screen.
1
افتح Workshop ثم All Requests. تظهر لك الطلبات الجديدة وقيد التنفيذ. افتح الطلب واقرأ Description، ويمكنك الاطلاع على تبويب History (This Year) لترى ما عُمل لهذه المركبة هذا العام.
Open Workshop › All Requests, open a request and read its Description. The History (This Year) tab shows what this vehicle already had done this year.
2
إما أن تضغط Start لبدء العمل، أو — إذا كان الطلب غير مقبول — تكتب السبب في Rejection Reason ثم تضغط Reject. لن يقبل النظام الرفض بدون سبب مكتوب.
Either click Start, or — if the request is not accepted — write the reason in Rejection Reason and click Reject. The system will not reject without a reason.
3
أثناء التنفيذ، افتح تبويب Repair Report واملأ ما يلي: أولاً Work Type (نوع العمل المنفَّذ)، ثم بيانات الدخول والخروج Entry / Exit وOdometer Reading وTechnician والتكاليف.
While the job is open, go to the Repair Report tab: set Work Type first, then entry/exit, odometer, technician and costs.
4
اضغط Complete لإنهاء الطلب. تصل رسالة لمقدّم الطلب تلقائياً، ويمكنك أن تكتب له ملاحظة في Note to Requester قبل الإنهاء.
Click Complete. The requester is notified automatically; you can add a message for them in Note to Requester first.

نوع العمل المنفَّذ — Work Type What was actually done

Request Type هو ما طلبه صاحب المركبة، أما Work Type فهو ما نفَّذته الورشة فعلاً — وقد يختلفان، وهذا طبيعي.
على الشاشة / On screenالمقصود / Meaning

Maintenanceصيانة داخل الورشة

Other أخرى — يظهر حقل Other Work Type تكتب فيه ما تم عمله
شرطان لإنهاء الطلب:
١ — لا يمكن الضغط على Complete قبل اختيار Work Type.
٢ — إذا اخترت Spare Parts فلا بد من إدخال القطع في جدول Spare Parts Used أولاً.
Two conditions to close a request: a Work Type must be set, and if it is Spare Parts, the parts must be listed in Spare Parts Used first.

متى يمكن التعديل؟ When each field can be edited

الحالة / Statusما يمكن عمله / What is possible
New البدء أو الرفض فقط. تقرير الإصلاح مُقفل. Start or Reject only; the report is locked.
In Progress تقرير الإصلاح مفتوح للتعديل، ومنه Work Type. The repair report is editable.
Completed الطلب مُقفل ولا يُعدَّل. Closed; nothing can be edited.
تقرير الإصلاح يظهر لمدير الورشة والفني فقط — لا يراه مقدّم الطلب. وتصل لك رسالة داخل النظام (الجرس 🔔) عند وصول كل طلب جديد.
The Repair Report tab is visible to the manager and technician only. You are notified in Odoo (🔔) whenever a new request arrives.
