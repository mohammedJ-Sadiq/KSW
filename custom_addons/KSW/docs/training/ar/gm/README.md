# أدلة المدير العام

**للمدير العام.** تغطّي هذه الأدلة مراحل الاعتماد الخاصة بك في الإجازات
والسلف الخاصة، وأداة إعادة الإجازة إلى معتمِد سابق.

> هل هذه أول مرة؟ ابدأ بـ **[البدء في استخدام النظام](../00-getting-started.md)**

## ما يمكنك فعله

| أريد أن… | الدليل |
|---|---|
| أعتمد إجازة سنوية (أولي أو نهائي) | [الإجازات: اعتماد المدير العام](01-leave-gm-approvals.md) |
| أُعيد إجازة إلى معتمِد سابق | [إعادة إلى المعتمِد](02-return-to-approver.md) |
| أُصادق على سلفة خاصة في المرحلة النهائية | [السلف الخاصة: الاعتماد النهائي](03-loan-gm-approval.md) |
| أعتمد عمولات ومستحقات أقسامي الشهرية | [اعتماد عمولات الشهر](04-commission-approval.md) |

## قاعدة ذهبية

- في العمولات تعتمد **الأقسام التي أنت مديرها العام فقط**، من
  **Commissions ← Monthly Pay Run**. أمّا إقفال شهر كامل أو إعادة فتحه فيخصّ
  **المدير العام للشركة**.
