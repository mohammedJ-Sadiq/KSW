# أدلة فريق تقنية المعلومات

**لفريق تقنية المعلومات** — من يستقبل تذاكر الدعم ويفرزها ويعالجها، ومن يملك
سجل الأصول التقنية في الشركة.

> هل هذه أول مرة تستخدم النظام؟ ابدأ بالدليل العام:
> **[البدء في استخدام النظام](../00-getting-started.md)**

## ما يمكنك فعله

| أريد أن… | الدليل |
|---|---|
| أفرز التذاكر الواردة وأحدّد أولوياتها وأكلّف بها | [إدارة قائمة التذاكر](01-ticket-queue.md) |
| أعالج التذكرة وأغلقها أو أعيد فتحها | [معالجة التذكرة وإغلاقها](02-resolve-and-close.md) |
| أسجّل الحواسب والهواتف وبقية الأجهزة | [سجل الأصول التقنية](03-asset-register.md) |
| أسلّم جهازًا لموظف كعهدة وأسترجعه منه | [تسليم العهد واسترجاعها](04-assign-and-return-assets.md) |
| أرسل جهازًا للصيانة، وأسجّل المفقود، وأتابع الضمان | [الصيانة والفقد والضمان](05-maintenance-and-warranty.md) |
| أطّلع على ما تمت معالجته وبأي سرعة | [التقارير وسجل التذاكر](06-reporting-and-history.md) |
| أعدّل المراحل والتصنيفات | [الإعدادات](07-configuration.md) |

## كيف يُقسَّم التطبيق

| القائمة | من يراها |
|---|---|
| **تذاكري** | الجميع — تذاكرك أنت، كأي موظف |
| **جميع التذاكر** | فريق تقنية المعلومات — لوحة العمل |
| **سجل التذاكر** | فريق تقنية المعلومات — كل التذاكر المغلقة |
| **التقارير** | فريق تقنية المعلومات — الأعداد والتصنيفات وزمن المعالجة |
| **الأصول التقنية ← الأصول / العهد / الصيانة** | فريق تقنية المعلومات وحده |
| **الإعدادات ← مراحل التذكرة / تصنيفات التذاكر / تصنيفات الأصول** | فريق تقنية المعلومات وحده |

## القواعد الأساسية

- **نوعان من التذاكر، والنوع ثابت.** **العُطل** شيء معطّل (`INC…`)، و**طلب
  الخدمة** شيء مطلوب (`REQ…`). النوع يحدّد رقم التذكرة ولا يُعدّل بعد
  إنشائها.
- **التذكرة هي السجل.** اتصال هاتفي لم يُدوَّن في التذكرة كأنه لم يحدث.
  استخدم **خارجي** لمخاطبة الموظف، و**الملاحظات** للتدوين الداخلي.
- **لا يحرّك التذكرة إلا فريق تقنية المعلومات.** المرحلة والمكلَّف بالمعالجة
  وحالة المعالجة من صلاحيتكم وحدكم؛ الموظف يراها ولا يغيّرها.
- **الأصول التقنية لكم وحدكم، والعهدة إجراء لا حقل.** لا تكتب في حقل
  **المكلَّف/الموظف** يدويًا؛ سلّم واسترجع عبر **تسليم عهدة لموظف**
  و**استرجاع العهدة** ليبقى السجل صحيحًا.
- **أغلق التذكرة حين تنتهي المعالجة فعلًا.** زمن المعالجة يُحسب من الإنشاء
  إلى الإغلاق، وكل التقارير مبنية عليه.
