# دليل استخدام نظام KSW

هذا المجلد هو المرجع الدائم الذي يجيب عن سؤال «كيف أفعل…؟» لكل من يستخدم نظام
الموارد البشرية والرواتب في KSW. وهو مُنظَّم **حسب الدور**: ابحث عن دورك في
الجدول أدناه واقرأ القسم الخاص بك فقط.

تتوفّر الأدلة بلغتين، متطابقة ملفًا بملف:

- **العربية** → هذا المجلد (`ar/`)
- **English** → [`en/`](../en/)

صور **الأدلة العربية** مأخوذة بواجهة عربية وتوجد في [`screenshots-ar/`](../screenshots-ar/). (صور الأدلة الإنجليزية في [`screenshots/`](../screenshots/).)

---

## أي دليل أقرأ؟ (الدور ← الشخصية)

قد تحمل أكثر من دور واحد. اقرأ كل شخصية تنطبق على عملك.

| وظيفتي / ما أقوم به | اقرأ دليل هذه الشخصية |
|---|---|
| أي منسوب — أطّلع على حضوري، أطلب إجازة أو سلفة خاصة، أشاهد كشف راتبي | **الموظف** → [`employee/`](employee/) |
| أدير فريقًا / أعتمد طلبات فريقي (خطوة الاعتماد الأولى) | **المشرف** → [`supervisor/`](supervisor/) |
| أعمل في الموارد البشرية — اعتماد الإجازات والسلف الخاصة، إنشاء السلف والجزاءات | **الموارد البشرية** → [`hr/`](hr/) |
| أعمل في المحاسبة — اعتماد السلف الخاصة، تسجيل السداد، إنهاء العمولات | **المحاسبة** → [`accounting/`](accounting/) |
| أنا المدير العام — الاعتماد الأولي والنهائي، إعادة الطلب للمراجعة | **المدير العام** → [`gm/`](gm/) |
| أُشغِّل الرواتب الشهرية — توليد كشوف الرواتب وتصدير ملف البنك | **الرواتب** → [`payroll/`](payroll/) |
| أدير الخصومات على مستوى الشركة / أضبط أنواع الخصومات | **مسؤول الخصومات** → [`admin/deductions.md`](admin/) |
| أضبط مكوّنات المستحقات ومواقع العمل والقواعد والمندوبين، أو أعمل مسؤولًا للعمولات | **مسؤول/مشرف العمولات** → [`admin/commissions.md`](admin/) |
| أعمل في فريق تقنية المعلومات — أعالج تذاكر الدعم وأدير سجل الأصول التقنية | **فريق تقنية المعلومات** → [`it/`](it/) |

> **جديد على النظام؟ ابدأ من هنا مهما كان دورك:**
> [البدء](00-getting-started.md) — تسجيل الدخول والتنقّل والإشعارات ومرشّح
> «بانتظار إجرائي» الذي يستخدمه كل معتمِد.

## كيف تُصان هذه الأدلة

- **المصدر المرجعي:** يصف كل دليل النظام كما هو فعليًا. عند تغيّر أي مسار عمل أو
  زر، حدِّث الدليل المعني (ونسخته الإنجليزية).
- **الصور:** تُلتقط من نظام **التطوير** فقط (`KSW_dev.conf` / `odoo_dev` /
  `localhost:8070`) — لا من الإنتاج أبدًا. لإعادة توليدها راجع
  [`tools/`](../tools/).
- **المصطلحات العربية** تتبع المسرد المعتمد في
  `custom_addons/KSW/ar_glossary_review.csv`. استخدم المصطلح المعتمد ولا
  تترجم حرفيًا.

## التصدير إلى PDF (اختياري)

يمكن تحويل أي دليل إلى كتيّب قابل للطباعة، مثال:

```bash
pandoc ar/employee/*.md -o KSW-Employee-Guide-AR.pdf
```
