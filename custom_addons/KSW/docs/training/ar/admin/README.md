# أدلة المسؤولين

للموظفين الذين **يضبطون ويشرفون** على مجالات كاملة في النظام بدل معالجة الطلبات
الفردية.

> ابدأ بـ[البدء](../00-getting-started.md).

## ماذا يمكنك أن تفعل

| مجالك | الدليل |
|---|---|
| الإشراف على كل الخصومات وضبط أنواع الخصومات | [إدارة الخصومات](deductions.md) |
| ضبط إعدادات العمولات (الفئات، المواقع، القواعد، المندوبون) | [إدارة العمولات](commissions.md) |

## القواعد الذهبية

- تغييرات الإعدادات تؤثّر على **الجميع** — غيّر الكتالوجات (الأنواع، الفئات،
  القواعد) بتروٍّ.
- يستطيع مسؤولو/مديرو الخصومات الرؤية والتصرّف على مستوى الشركة؛ التزِم بمجال
  مسؤوليتك.
