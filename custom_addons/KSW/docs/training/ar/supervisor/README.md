# أدلة المشرف / المدير المباشر

**للمشرفين والمديرين المباشرين.** تغطّي هذه الأدلة المهام التي تؤدّيها
لفريقك: الاعتماد، وكشوف الحضور، وتسجيل المستحقات الإضافية والعمولات.

> هل هذه أول مرة؟ ابدأ بـ **[البدء في استخدام النظام](../00-getting-started.md)**

## ما يمكنك فعله

| أريد أن… | الدليل |
|---|---|
| أعتمد إجازة لأحد مرؤوسي | [اعتماد الإجازات](01-approve-time-off.md) |
| أؤكّد مباشرة أحد مرؤوسي بعد عودته من إجازته السنوية | [تأكيد المباشرة](08-confirm-return.md) |
| أعتمد سلفة خاصة لأحد مرؤوسي | [اعتماد السلف الخاصة](02-approve-loan.md) |
| أسجّل حضور فريقي الشهري | [كشوف الحضور](03-attendance-sheets.md) |
| أسجّل العمل الإضافي والردود والوجبات والبدلات والمكافآت | [تسجيل المستحقات الإضافية](04-commission-pay-entries.md) |
| أُعدّ بدلًا يتكرّر كل شهر | [الإدخالات المتكرّرة](05-commission-recurring.md) |
| أُسلّم الشهر وأفهم كيف يُصرَف | [الدورة الشهرية](06-commission-monthly-cycle.md) |
| أطّلع على قسائم رواتب فريقي | [قسائم رواتب الفريق](07-view-team-payslips.md) |
| أرفع تذكرة دعم فني نيابة عن أحد مرؤوسي | [تذكرة دعم فني لأحد مرؤوسي](09-ticket-for-team-member.md) |

## قاعدة ذهبية

- في العمولات، **تقديم الدفعة ليس التسليم.** لا يصل قسمك إلى المدير العام إلا
  حين تضغط **Submit My Entries**.
