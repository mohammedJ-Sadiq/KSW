Confirming a Return from Annual Leave

Who is this for: Supervisor / Direct Manager How long it takes: 1 minute per employee

What this does

Records the date one of your team actually came back to work after annual leave, and closes out that leave's return status. This is a separate step from approving the leave itself — it happens after the leave is fully approved and the employee has already gone on vacation.

Why this matters

  • Payroll is blocked for any employee whose annual leave still shows as "On Vacation" with no confirmed return. If you don't confirm it, that employee's payslip cannot be generated — even if they are already back at work and being paid as normal.
  • It gives HR and Accounting a reliable record of who has actually returned, separate from the dates on the original request (people sometimes come back early or late).
  • This is exclusively your responsibility. Odoo only lets the leave's Direct Manager confirm a return — not the employee, and not HR. If you don't do it, no one else will.

Before you start

  • The leave must already be fully approved — the record shows an 🏖️ On Vacation ribbon.
  • You need the employee's actual return date on hand (it may differ from the date originally requested).
  • The Confirm Return button only appears for the leave's own Direct Manager — if you don't manage that employee, you won't see it.

Where to find it

Two ways to reach it:

  • Fastest: open the Time Off app → Management → Return Confirmation. This list shows only leaves that are currently "On Vacation" and still need a return date — for yourself and your direct reports. Nothing else clutters the list.
  • Alternative: open the leave directly from Management → Time Off, the same place you go to approve any other request.

Steps

  1. Open the employee's leave from Management → Return Confirmation (or Management → Time Off).
  2. Check the Return Date field and fill in the employee's actual return date if it isn't already set.
  3. Click Confirm Return. The leave's Return Status changes to ✅ Return Confirmed.

What happens next

  • The leave's Return Status badge changes from 🏖️ On Vacation to ✅ Return Confirmed.
  • The employee's next payslip is no longer blocked by this leave.
  • A note is posted on the leave's chatter recording who confirmed the return and when — useful if HR or Accounting ask about it later.

A note on the Refuse button

Once a leave has cleared the General Manager's final approval — including while it is waiting on HR's final document confirmation — the Refuse button is no longer available on it. At that stage the only action left is confirming the return date; refusing an already-approved, already-taken vacation doesn't make sense.

Common issues

Symptom Cause Fix
I don't see Confirm Return on the leave The leave isn't fully approved yet, no return date is set, or you're not this employee's Direct Manager Fill in the Return Date field first; if the button still doesn't appear, check that you're set as their Direct Manager
The leave doesn't appear in Return Confirmation It's already confirmed, or it isn't a fully-approved annual leave Check Management → Time Off and the leave's status bar
I can't confirm a leave that isn't mine or my team's Only the employee's Direct Manager can confirm a return — there is no other route If their Direct Manager is unavailable, ask HR to update the employee's Direct Manager field first
