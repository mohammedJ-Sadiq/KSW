# HR Guides

For **HR staff**. You approve leave and loans at the **HR step**, create
**salary advances**, own all **installment changes**, review attendance sheets,
and run the **bank file export**.

> You also do everything an [Employee](../employee/) does. Start with
> the **General guide** ([Getting Started](../00-getting-started.md)).

## What you can do

| I want to… | Guide |
|---|---|
| Approve leave at the HR step (and confirm the signed annual-leave form) | [Leave: HR approval](01-leave-hr-approval.md) |
| Approve a loan at the HR step | [Loan: HR approval](02-loan-hr-approval.md) |
| Create a salary advance | [Create a salary advance](03-create-deductions.md) |
| Change installments / mark paid / record a loan payment | [Modify deductions & change installments](04-modify-deductions.md) |
| Review attendance sheets | [Attendance sheets (HR review)](05-attendance-sheet-management.md) |
| Export the salary/commission bank file | [Payroll → Bank file export](../payroll/03-bank-file-export.md) |

## The golden rules

- **Time-off** approvals live in **Time Off → Management → Time Off**;
  **loan** approvals live in **Loans → Operations → Loans** (opens on
  **Waiting For Me**).
- On **annual leave** you act **twice**: the HR approval step, and the final
  **HR confirmation** of the signed form.
- **You create salary advances; you own all installment changes** (edit
  schedules, mark installments paid, record loan payments).
- **Penalties** (government + internal) are created by **Accounting**, not HR.
- On attendance sheets you **review** only — you edit a sheet just for employees
  you directly manage.
