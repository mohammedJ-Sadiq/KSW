# Payroll Guides

For the **payroll initiator** — the person who runs the monthly payroll. You
create the payslip batch, generate the payslips, resolve any employees the
system skipped, and export the bank transfer file.

> Start with the **General guide** ([Getting Started](../00-getting-started.md)).

## What you can do

| I want to… | Guide |
|---|---|
| Create a batch and generate payslips | [Generate a payslip batch](01-generate-payslip-batch.md) |
| Fix employees the system skipped | [Resolve skipped employees](02-skipped-employees.md) |
| Export the bank transfer file | [Bank file export](03-bank-file-export.md) |

## The golden rules

- Payroll for an employee is **blocked** if they have an **unconfirmed
  annual-leave return** — those employees are *skipped* and must be resolved.
- Loan and penalty installments, and attendance deductions, flow into payslips
  automatically — you don't enter them by hand.
- The bank file is generated **per bank**, with NET totals shown on the batch.
